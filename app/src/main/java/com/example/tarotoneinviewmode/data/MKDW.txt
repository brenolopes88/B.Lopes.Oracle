## O App — TarotOneInViewMode

Stack: Kotlin, Jetpack Compose, Material3, Navigation Compose
SDK: minSdk 24, targetSdk 36
Arquitetura: MVVM com Repository pattern
Estado: StateFlow / mutableStateOf

## Estrutura atual
- 3 telas: Archive (lista por naipe), CardDetail (detalhe), Draw (tiragem)
- TarotCard: modelo rico com essence, lightMeaning, shadowMeaning,
  guidanceWhenReversed, correspondences, history
- Arcanos Maiores completos (22 cartas)
- Arcanos Menores: Copas completo, Paus/Espadas/Pentáculos vazios
- Tema escuro com paleta: DeepIndigo, TarotGold, EmeraldGlow, EtherBlue
